# Verification Report Export

CodeProof can export a migration run as a self-contained HTML verification report and open the same report in a print dialog for PDF export.

The report contains:

- Source and target language
- Verification score and status
- Passed/total tests
- Compilation and runtime errors
- Execution time
- AI confidence and provider
- Source and generated code
- Behavioral test evidence
- Human-readable failure explanation

Use **Download Report** to save the HTML report, or **Print / Save PDF** and choose **Save as PDF** in the browser print dialog.
